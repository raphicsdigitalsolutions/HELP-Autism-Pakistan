## 3. Responsive & Accessibility Audit

- **Player Container:** `.video-embed-wrapper` with responsive CSS `aspect-ratio: 16 / 9; width: 100%; overflow: hidden; background: #000000;`
- **Fallback for older browsers:** `@supports not (aspect-ratio: 16 / 9) { padding-bottom: 56.25%; height: 0; }`
- **Iframe Attributes:**
  - `loading="lazy"`
  - `allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share"`
  - `allowfullscreen`
  - Descriptive, accessible `title` attribute matching video title and organization branding
- **Tested Viewport Breakpoints:**
  - Mobile: 320px, 340px, 360px, 375px, 390px, 414px, 430px
  - Tablet: 768px, 820px, 900px
  - Desktop: 1024px, 1280px, 1366px, 1440px, 1920px
  - Results: No horizontal overflow, no player clipping, touch-friendly tap targets (>44px), smooth scrolling.
